Requirements
OS: Windows (Makefile config)
Developed and tested on Windows 11

Compiler: clang++ with C++23 support

Build system: Just Makefile

Clone and Build
The repository does not need any third-party dependencies directly, so a normal clone is enough:

git clone https://github.com/nicospecovius04-dot/4-Gewinnt-Umgedreht-Jane-Street-Puzzle/.git
Then configure and build the project:

make

Tests are optional and disabled by default so a normal configure works without network access.

Just uninclude Raylib to run with no libs
